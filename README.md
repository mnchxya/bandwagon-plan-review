## THE PLAN 测评：性能先泼冷水，线路再给糖

一句话概括这个套餐的价值结构：性能是普通低价 VPS 的水平，网络是高端线路的水平，钱都花在了线路上。

### CPU 和跑分：够用，但没有“尊贵感”

标称 2 核，主频 2.6GHz 档，但这是限额资源——有测评算过，实际可用量大约相当于完整 1 核的 45%。Geekbench 5 跑分单核 343、多核 534，放在低价 VPS 里算正常水平，放在 THE PLAN 的价位就显得普通。The DC9 Plan 那台还叠加了积分（credits）策略，持续高负载会被限制得更明显。

实际影响取决于你跑什么：建站、代理、轻量服务完全无感；编译、视频转码、高并发这类 CPU 密集任务，和给完整核心的常规 CN2 GIA-E 套餐会有肉眼可见的差距。

### 磁盘：大块吞吐不错，4K 随机偏弱

fio 实测数据：1M 大块读写总吞吐约 865 MB/s，顺序性能没问题；4K 随机读写只有 14 MB/s 上下（约 3.6k IOPS）。跑代理、反向代理、静态站没有压力，频繁小文件读写的应用（某些数据库场景）会感到吃力。初代版本的磁盘 IO 实测约 405 MB/s，代际之间有些波动，总体属于中规中矩。

### 网络：真正值钱的部分

几份公开测评的 traceroute 记录基本一致：

- **回程线路**：电信走 CN2 GIA（59.43 骨干网直连回国），联通回程同样经电信 GIA，移动方向 2024 年起在 DC6/DC9 接入了 CMIN2。三网全是高端线路，这是 $99 价位少见 even 罕见的配置。
- **延迟**：上海电信约 126–132ms，北京电信约 148–177ms，广深约 154–165ms，晚高峰波动不大。
- **速度**：国内单线程下载能跑到 100 Mb/s 以上，国际方向走 10G 端口，新版带宽 2.5Gbps。
- **流媒体和解锁**：初代实测 TikTok 可解锁美区；各机房之间的解锁差异不小，香港、大阪、温哥华这些节点的体验普遍好于普通洛杉矶机房——买之后多切换几个机房自测，比纠结参数更有用。
